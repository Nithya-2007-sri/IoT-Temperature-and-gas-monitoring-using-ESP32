# IoT Temperature and Gas Monitoring Using ESP32

## Project Overview
The IoT Temperature and Gas Monitoring System is an embedded system developed using ESP32 to monitor environmental temperature and gas levels. It uses DHT22, MQ-2 and MQ-5 sensors to collect readings and displays the information on an LCD.

The system compares the sensor readings with predefined threshold values and indicates the environmental condition as SAFE or DANGER.

## Objectives
- To monitor environmental temperature.
- To detect gas and smoke levels.
- To display real-time sensor readings.
- To identify unsafe environmental conditions.
- To develop a low-cost and simple monitoring system.

## Components Required
- ESP32 Development Board
- MQ-2 Gas Sensor
- MQ-5 Gas Sensor
- DHT22 Temperature and Humidity Sensor
- LCD Display
- Connecting Wires
- Power Supply

## Software Requirements
- Arduino IDE
- ESP32 Board Package
- DHT Sensor Library
- LCD Library

## Features
- Temperature monitoring using DHT22.
- Gas detection using MQ-2 and MQ-5 sensors.
- Real-time readings displayed on LCD.
- Threshold-based SAFE and DANGER indication.
- Offline monitoring without internet connectivity.

## Working Principle
The MQ-2 and MQ-5 sensors detect gas levels in the surrounding environment. The DHT22 sensor measures temperature and humidity. The ESP32 processes the sensor readings and compares them with predefined threshold values. The readings and safety status are displayed on the LCD.
